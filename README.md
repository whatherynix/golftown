# Golf Town Customer & Store Credit Management Platform (Q1 2026)

A professional, full-stack enterprise application built for managing customer records, tracking store credit liabilities, multi-store location insights, automated Telegram alerts, secure email notifications, and interactive analytics.

## 🚀 Key Features

- **Store Credit & Refund Management**: Comprehensive tracking of customer balances, store credit issuances, and refund histories across all Canadian retail locations.
- **Interactive Recharts Analytics**: Real-time visualization of total store credit balances, multi-store liability distributions, customer holder counts, and Q1 2026 liability growth trends.
- **Automated Telegram & Webhook Alerts**: Configurable scheduled triggers (such as daily refund status summaries and instant high-value credit alerts) dispatched directly to Telegram groups/channels.
- **Multi-Store Mapping & Store Finder**: Detailed store locator modal with store hours, phone contacts, addresses, and credit metrics.
- **Batch Operations & Data Export**: Multi-select customer records for bulk email dispatch, CSV export, and AI-powered name/insight generation.
- **Express & Vite Full-Stack Architecture**: Robust backend proxy server with Vite middleware for optimal performance and containerized cloud deployment.

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Recharts, Motion.
- **Backend**: Node.js, Express, TypeScript, Nodemailer, XLSX processing.
- **Build System**: Vite & Esbuild.

## 📦 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
